# Skills

A collection of Agent Skills for use with Claude Code, OpenCode, and other AI coding agents.

## Skills

- **[agent-engineering](./skills/agent-engineering/)** — Build and audit AI agent systems. Covers agent architecture, loops, tool design, system prompt engineering, context management, safety, and anti-patterns.

## Usage

```bash
npx skills add https://github.com/thekernelkiller/skills --skill agent-engineering
```
